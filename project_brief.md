# My agent: smart-pantry
One-liner: A conversational agent that helps users manage their pantry inventory, discover recipes, and track kitchen ingredients.

Tool coverage:
- Memory: User dietary preferences, allergies, favorite cuisines, and household size
- Tools: Search pantry items, add new items to pantry inventory, update quantities, search recipes by ingredient
- Catalog/UI: Pantry inventory catalog and recipe collection
- Image gen: Visual representations of prepared dishes
- Sandbox: Nutritional calculations (calories, macronutrients)

Recommended for every project: memory, storage, tools, image generation, A2UI
